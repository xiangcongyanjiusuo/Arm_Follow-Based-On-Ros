# 标定操作手册

## 准备工作

1. 确保机械臂已上电，`arm_tf_node` 正常运行
2. 确保相机已连接，图像话题 `/image_raw` 有数据
3. 准备棋盘格标定板（9列×6行内角点，方格边长27mm）

## 第一步：相机内参标定

```bash
ros2 run vision_pkg camera_intrinsic_calibration_node
```

**操作步骤：**
1. 将棋盘格放在相机视野内
2. 不断变换棋盘格的位姿（倾斜、旋转、远近），保持棋盘格完整可见
3. 每次看到画面中棋盘格角点被正确标记后，按**空格键**采集
4. 重复采集至少 **15 张**不同位姿的图像
5. 按 **C 键**计算标定结果，查看重投影误差
6. 如果误差 < 0.5 像素，按 **S 键**保存为 `camera_intrinsics.yaml`
7. 如果误差过大，按 R 重置重新采集

**注意事项：**
- 棋盘格要覆盖画面的各个区域（四角、中心）
- 包含不同距离（近、中、远）
- 包含不同角度（正对、倾斜、旋转）
- 避免棋盘格反光或模糊

## 第二步：手眼标定

```bash
ros2 run vision_pkg camera_calibration_node
```

**操作步骤：**
1. 将棋盘格**固定在桌面上**不动
2. 操纵机械臂移动到不同位姿，使相机从不同角度能看到棋盘格
3. 每次棋盘格被正确检测后，按**空格键**采集一对样本（机械臂位姿+棋盘格图像位姿）
4. 采集至少 **15 对**样本
5. 按 **C 键**计算手眼标定结果
6. 如果误差 < 10mm，按 **S 键**保存为 `hand_eye_result.yaml`

**注意事项：**
- 棋盘格必须保持不动
- 机械臂移动范围尽量大，覆盖不同的姿态
- 避免相机太远导致棋盘格检测失败
- 确保采集时 arm_tf_node 在正常运行

## 第三步：桌面高度（自动计算）

**无需手动测量。** 手眼标定过程中棋盘格放在桌面上，标定完成后会自动计算桌面在基坐标系下的高度，并保存到 `hand_eye_result.yaml` 中。

如果需要手动覆盖（比如换了桌子），可在启动 `box_tf_node` 时指定参数：
```bash
ros2 run vision_pkg box_tf_node --ros-args -p table_height_mm:=你的桌面高度
```

## 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 棋盘格检测不到 | 角点数量不对 | 用 chessboard_diag 节点确认棋盘格规格 |
| 内参标定误差大 | 图像质量差或样本不足 | 增加样本数量，注意光照和对焦 |
| 手眼标定误差大 | 棋盘格移动了 | 确保棋盘格固定，重新采集 |
| 手眼标定误差大 | arm_tf_node 未运行 | 检查 TF 是否正常发布 |
| 坐标转换不准 | 桌面高度不对 | 重新精确测量桌面高度 |
