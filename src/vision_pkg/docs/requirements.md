# 项目需求文档

## 项目名称

机械臂视觉跟随系统（Eye-in-Hand）

## 项目目标

通过装在机械臂夹爪末端的单目相机，实时检测目标盒子，并将图像像素坐标转换为机械臂基坐标系下的真实三维坐标，为后续机械臂跟随抓取提供位置信息。

## 硬件配置

| 组件 | 型号/规格 |
|------|----------|
| 机械臂 | SO-ARM100，6轴，中文关节命名 |
| 相机 | USB单目摄像头，装在夹爪末端（眼在手） |
| 标定板 | 棋盘格（9x6内角点，27mm方格） |
| 目标物体 | 彩色盒子（已知尺寸），放置在桌面上 |

## 功能需求

### F1：相机内参标定
- 使用棋盘格标定相机内参（相机矩阵K、畸变系数D）
- 输出 YAML 格式标定文件
- 显示重投影误差评估标定质量

### F2：手眼标定
- 眼在手（eye-in-hand）标定模式
- 使用标定后的相机内参
- 计算相机坐标系到末端执行器坐标系的变换矩阵
- 输出 YAML 格式结果文件

### F3：目标检测
- 基于 HSV 色彩空间的颜色检测（已有）
- 输出目标在图像中的像素坐标和包围框
- 可配置的 HSV 阈值

### F4：坐标转换
- 将像素坐标转换为机械臂基坐标系下的三维坐标
- 利用桌面平面约束估算深度
- 发布 TF 变换和 PointStamped 消息

### F5：实时跟踪
- 实时显示目标在基坐标系下的位置
- 在 RViz 中可视化 target_object TF 帧

## 精度要求

| 指标 | 目标值 |
|------|--------|
| 相机内参标定重投影误差 | < 0.5 像素 |
| 手眼标定误差 | < 10mm |
| 坐标转换精度 | < 10mm |

## 约束条件

- 目标盒子必须放置在桌面上（深度估计依赖平面约束）
- 机械臂运行期间 arm_tf_node 必须正常发布 TF
- 相机相对末端执行器的安装位置固定不变
